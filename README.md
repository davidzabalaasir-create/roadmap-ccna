# Roadmap CCNA 200-301 v2.0

Plan de estudio de 22 semanas para la certificación CCNA de Cisco (examen 200-301, temario v2.0), en formato web.

**Web:** https://davidzabalaasir-create.github.io/roadmap-ccna/

- Bloques oficiales del temario y su peso (v2.0 y v1.1).
- Seis fases con objetivos por semana y laboratorios de Packet Tracer.
- Progreso con casillas, guardado en el navegador (localStorage).
- Simulacros, criterio para presentarse y recursos gratuitos y de pago.

Web estática sin dependencias: `index.html`, `assets/styles.css`, `assets/data.js` (contenido) y `assets/app.js`. El plan completo en texto está en [ROADMAP-CCNA.md](ROADMAP-CCNA.md).

Plan personal de estudio, no afiliado a Cisco.
